# unknown shop

Магазин подписок на доступ к нейросетям по API: Telegram-бот, собственный API-эндпоинт и сайт с документацией.

- **Бот:** [@UnknownAiShopBot](https://t.me/UnknownAiShopBot)
- **Эндпоинт для клиентов:** `https://154-83-140-29.sslip.io/v1` (OpenAI- и Anthropic-совместимый)
- **Сайт:** две страницы — «Главное» (тарифы, FAQ) и «API» (документация)

## Введение в дело

**Что продаём.** Подписку на 30 дней к 49 моделям: 32 текстовые (GPT-6, Claude, Gemini, Grok, Qwen, DeepSeek…), 8 для изображений, 9 для видео. Тарифы: **Pro — $33** и **Unlimited — $80**. Start и Creator скрыты из продажи (`on_sale=False` в каталоге), но действующие подписки на них работают.

**Откуда доступ.** Модели предоставляет провайдер UseitAI (`https://useitai.top/api/v1`). У магазина есть пул ключей провайдера по тарифам. Клиент ключ провайдера не видит: он получает свой ключ `sk-us-…` и ходит через наш эндпоинт.

**Как проходит покупка:**

1. Клиент выбирает тариф в боте или нажимает «Купить» на сайте (кнопка открывает бота сразу на тарифе).
2. Платит Telegram Stars или криптой через Crypto Pay (@CryptoBot). Оба способа проверяются автоматически.
3. Бот берёт свободный ключ провайдера из пула, закрепляет его за клиентом и присылает клиенту ключ `sk-us-…` и адрес эндпоинта.
4. Эндпоинт на каждый запрос проверяет ключ и активную подписку, подставляет ключ провайдера и пересылает запрос (включая потоковые ответы).
5. Подписка кончилась — эндпоинт перестаёт пропускать запросы, а ключ провайдера возвращается в пул для следующего покупателя.

**Что делает админ** (команды в боте, `/admin` — список):

- `/addkeys pro` + ключи с новой строки — пополнить пул. Кто оплатил, пока пул был пуст, получит ключ сразу после пополнения (сначала те, кто купил раньше).
- `/givekey user_id ключ` — выдать конкретный ключ вручную.
- `/grant user_id тариф [дней]` — подписка без оплаты.
- `/stats`, `/keys`, `/user user_id` — статистика, остаток пула, карточка клиента.
- Поддержка: вопрос клиента из раздела «Поддержка» приходит админам с карточкой клиента — ответьте на него реплаем, и бот перешлёт ответ клиенту.
- `/revoke_list`, `/revoked ключ` — ключи, выданные клиентам напрямую до включения эндпоинта, которые надо отключить у провайдера.

## Архитектура

```
Клиент ──HTTPS──▶ Caddy (443) ──▶ эндпоинт 127.0.0.1:8081 ──▶ useitai.top/api/v1
Telegram ◀──────▶ бот (aiogram, long polling)
                    │
                    ├── SQLite data/bot.db (пользователи, подписки, платежи, пул ключей)
                    ├── фоновая задача: напоминания и окончание подписок (раз в 10 мин)
                    └── фоновая задача: проверка счетов Crypto Pay (раз в 15 с)
Сайт (статичный) ── Netlify, папка docs/dist
```

Бот, эндпоинт и фоновые задачи работают в одном процессе.

## Структура репозитория

```
bot/
  __main__.py        запуск: бот, эндпоинт, фоновые задачи
  config.py          настройки из .env
  catalog.py         модели, тарифы, FAQ — меняйте здесь
  db.py              SQLite: подписки, платежи, ключи, счета, ключи клиентов
  gateway.py         собственный API-эндпоинт (прокси к провайдеру)
  texts.py           тексты сообщений бота
  handlers/          меню и разделы, оплата, админка
  services/          выдача доступа, Crypto Pay, окончание подписок
  keyboards/         кнопки
  web/server.py      бэкенд веб-чата (сейчас выключен, WEB_ENABLED=false)
docs/
  pages/             шаблоны страниц сайта (без стилей — не открывать напрямую)
  partials/          общие части: стили, 3D-фон, скрипты
  dist/              собранный сайт — его загружают на Netlify
scripts/build_docs.py  сборка сайта (тарифы и FAQ берутся из bot/catalog.py)
web/                 фронтенд веб-чата (не используется)
deploy/              установка и обновление на сервере
tests/               pytest
```

## Локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements-dev.txt
copy .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS и остальное
.\.venv\Scripts\python -m bot
```

Без `PUBLIC_API_URL` бот не запускается: клиенты получали бы ключи провайдера напрямую. Для такого режима (например, локальной проверки) нужно явно указать `ALLOW_DIRECT_KEYS=true`.

Проверки: `.\.venv\Scripts\python -m pytest` и `.\.venv\Scripts\python -m ruff check .`

Сайт: `.\.venv\Scripts\python scripts/build_docs.py` → результат в `docs/dist/`.

## Сервер

Ubuntu 24.04, Profitserver (Амстердам), `154.83.140.29`. Код в `/opt/unknownshop`, бот работает от пользователя `unknownshop` в песочнице systemd, наружу смотрит только Caddy (80/443).

- Первая установка: `deploy/setup.sh`, затем `deploy/gateway.sh` (Caddy, HTTPS, эндпоинт). Бот запустится после `gateway.sh`: он прописывает `PUBLIC_API_URL` в `.env`.
- Обновление: собрать архив `tar -czf update.tar.gz --exclude=__pycache__ bot deploy requirements.txt`, загрузить в `/root/` и выполнить `deploy/update.sh`. База и `.env` на сервере не трогаются.
- Логи: `journalctl -u unknownshop -f`, `journalctl -u caddy -f`.

## Секреты

В репозитории их нет и быть не должно. `.env` (токен бота, токен Crypto Pay), `data/` (база с ключами) и архивы деплоя исключены в `.gitignore`. Образец настроек — `.env.example`.
