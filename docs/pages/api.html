Как получить ключ

  1. Откройте Telegram-бот unknown shop и выберите тариф Pro или Unlimited.
  2. Оплатите в Telegram Stars или криптой через @CryptoBot. Ключ придёт сразу после оплаты.
  3. Ключ, тариф и срок действия всегда под рукой в боте по команде /profile.

Если ключ попал в чужие руки, откройте в боте «Профиль» → «Перевыпустить ключ»: старый ключ сразу перестанет работать, а вы получите новый.

Безопасность

Аутентификация

Передавайте ключ в заголовке Authorization. Для Anthropic SDK подойдёт и заголовок x-api-key.

http
Authorization: Bearer YOUR_API_KEY

Держите ключ в секрете. Храните его в переменной окружения и не вставляйте в код, который уходит в браузер или в публичный репозиторий.

Быстрый старт

Подойдёт любой OpenAI SDK, достаточно указать другой base URL. В примерах ключ берётся из переменной UNKNOWN_SHOP_API_KEY.

  -d '{
    "model": "gpt-6-astra",
    "messages": [
      {"role": "user", "content": "Объясни, что такое REST, в двух предложениях"}
    ]
  }'

Cursor OPENAI
  1. Откройте Cursor Settings → Models (Ctrl+Shift+J, на macOS Cmd+Shift+J).
  2. В блоке API Keys вставьте ключ в поле OpenAI API Key.
  3. Включите Override OpenAI Base URL и укажите https://154-83-140-29.sslip.io/v1.
  4. Нажмите Add Custom Model и введите ID модели, например claude-opus-5-5.
  5. Выберите модель в чате или в режиме Agent.
Cline, Roo Code, Kilo Code OPENAI
  1. Откройте настройки расширения (шестерёнка в его панели).
  2. API Provider: OpenAI Compatible.
  3. Base URL: https://154-83-140-29.sslip.io/v1, API Key: ваш ключ.
  4. Model ID: claude-opus-5-5 или любая другая модель.

С параметром "stream": true ответ приходит частями в формате Server-Sent Events. Каждая часть содержит фрагмент текста в delta.content. Поток заканчивается строкой data: [DONE].

  -H "Content-Type: application/json" \
  -N -d '{"model": "gpt-5.6-sol", "stream": true, "messages": [{"role": "user", "content": "Привет"}]}'

Ошибки

Ошибка возвращается с HTTP-кодом и телом в формате OpenAI. Ориентируйтесь на поле code: оно не меняется, а текст message может уточняться.

Ответ · 404
{
  "error": {
    "message": "Модель не найдена",
    "type": "invalid_request_error",
    "code": "model_not_found"
  }
}
HTTPcodeЧто произошло и что делать
400invalid_requestНеверные параметры запроса. Проверьте имена и значения полей.
401invalid_api_keyКлюч не передан или недействителен. Проверьте заголовок и ключ в /profile.
402subscription_requiredНет активного тарифа. Продлите подписку в боте.
404model_not_foundМодели с таким ID нет. Сверьтесь с разделом Модели.
429plan_limit_reachedДневной лимит тарифа исчерпан. Доступ вернётся после сброса, время сброса есть в заголовке X-Plan-Reset.
500server_errorВнутренняя ошибка. Повторите запрос через несколько секунд.
502upstream_errorСервис моделей временно не отвечает. Повторите запрос.
503key_pendingПодписка оплачена, доступ ещё готовится. Бот пришлёт уведомление, когда всё будет готово.
503provider_key_errorВременная проблема на нашей стороне, мы уже получили уведомление. Если ошибка не пропадает, напишите в поддержку.
Тарифы

Лимиты и тарифы

Отдельного ограничения на число запросов в минуту нет. Объём работы зависит только от тарифа: сколько часов в сутки действует безлимит на текст и видео.

Остаток по тарифу приходит в заголовках каждого ответа:

ЗаголовокЗначение
X-Plan-LimitДневной лимит тарифа.
X-Plan-RemainingСколько осталось до сброса.
X-Plan-ResetКогда лимит обновится.

Когда дневной лимит заканчивается, API отвечает кодом 429 с code: plan_limit_reached.
